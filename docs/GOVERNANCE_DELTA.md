## Milestone 1 design decisions

- Navy `#051039`, blue, white and restrained red are a provisional visual reference from the supplied PDF, not an approved brand specification. No approved brand asset was present; no CEVA logo was fabricated.
- Four menu groups and one role-restricted administration entry; native disclosure controls support keyboard/touch and a compact narrow-screen menu. Planned destinations are labeled, with no fake publication/approval controls.
- Separate organization, region, grouping, country and site fields. Benelux is a grouping. Initial country choices NL/BE/LU/GB (United Kingdom); blank country remains explicit. Only the two existing fictional fixtures receive synthetic country metadata. No real sites inferred.
- Location switch validates membership, stores an authorized selection and navigates to the same general area. Object detail pages return to My work when changing site, avoiding reuse of object IDs across locations. Form edits receive visible unsaved state and a leave-page confirmation.
- Header displays immutable source-baseline hash and local assessment version/rule. This is not a governed template version yet. The next milestone introduces immutable template/profile assignments; there is no mutable local question editor in this milestone.
- Overview shows unconfirmed CAT standing, section readiness and target separately; planned sessions are shown without invented due/overdue classification. No lowest-section or day-window logic added prematurely.
