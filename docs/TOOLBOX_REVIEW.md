The Django domain extension is additive. Input size, A4/A3/Business Process methodology, worksheet schema, local closure, global review and report version are independent. Revisions retain profile switches, worksheet rows, attachments, imports, event history and PDF snapshots. Stale writes are rejected. Existing approved assessment snapshots remain immutable. Response A and unknown scope do not earn a gate. Neither the 34% operational indicator nor a local maturity level is CAT certification.

## Permissions and file handling

Site access is checked on pages, mutations, exports, previews and downloads. Financial/HR classifications and currently linked evidence classifications are checked again on private attachment and report access. CSV/XLSX import keeps exact original bytes, requires a preview and explicit mapping, validates all rows before an atomic confirm and rejects replay. File type, size, image dimensions, ZIP size/parts and macro content have local limits. Formula-like CSV/XLSX text is exported inertly. A cross-site learning entry contains only a selected approach summary and explicit recipient scope; the recipient adaptation starts without source evidence, measurements, benefits, participants, reviews or TCA answers. Corporate malware scanning, durable shared storage, retention and sharing authority still require approved integration and policy.
