# Milestone plan

1. **Source and foundation.** Archive and hash exact workbook bytes. Inventory all sheets, cells, formulas, comments, validations, names, embedded parts, and mappings. Import 15 categories and 150 records transactionally and repeatably. Run source coverage checks and start a local app.
2. **Assessment domain.** Add sites, roles, responses, immutable snapshots, draft scoring, evidence and clause coverage. Test A handling, lower-level preservation, idempotence, history, and site authorization.
3. **Complete journey.** From a gap and evidence to a proposed PDCA event, results review, reassessment request, and new dated snapshot. Exercise the journey in a browser and retain the complete catalog.
4. **Remaining workflows.** Add six role-oriented screens, evidence preparation, sessions, improvement sequencing, and A4/A3/Business Process forms. Verify distinct conclusions and profile behavior.
5. **Reports and reuse.** Complete archive, concise PDCA, Excel mappings with text-limit errors, benefit controls, and accepted other-audit clause reuse. Test measurement comparability and counting.
6. **Pilot handover.** Security and concurrency tests, startup and restore exercise, browser review, workload measurement, and distinct final source/acceptance review. Record deployment decisions.

Do not mark a milestone complete solely because a scaffold or dashboard renders. `docs/STATUS.md` records the actual state and checks.
